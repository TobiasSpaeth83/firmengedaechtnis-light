# Firmengedächtnis light

Eine schlanke, teilbare Grundlage für das Küchenstudio von Felix: Dokumente aus Google Drive werden täglich verarbeitet, per OCR ausgelesen und als strukturierte Daten in einer Tabelle dokumentiert.

## Was dieses Repository leistet

- hält Abläufe, Entscheidungen und Wissen nachvollziehbar fest;
- beschreibt die Dokumentenautomatisierung in verständlichen Schritten;
- gibt Felix' lokalem Claude eine klare Routine für Einrichtung, Betrieb und Fehlerklärung;
- trennt vertrauliche Originaldokumente vom öffentlichen Prozesswissen.

## Start hier

1. Lies [die Einrichtung](docs/EINRICHTUNG.md).
2. Richte den Drive-Eingangsordner und die Zieltabelle ein.
3. Verwende [die tägliche Claude-Routine](docs/CLAUDE_ROUTINE.md), um die Automatisierung gemeinsam einzurichten.
4. Prüfe den ersten Lauf mit [der Beispieltabelle](data/dokumentenregister.csv).

## Datenschutz

Dieses Repository ist öffentlich. Keine Kundenbelege, Rechnungen, personenbezogenen Daten, Zugangsdaten oder Drive-Links hier ablegen. Es enthält ausschließlich Anleitungen, Datenstruktur und anonymisierte Beispiele.

## Zielprozess

`Google Drive Eingang` → `OCR` → `Validierung` → `Dokumentenregister` → `Archiv / Fehlerliste`
Teilbare Vorlage für ein kleines Firmengedächtnis und Dokumentenautomatisierung
