# Gemeinsame Vorlagen

Hier liegen von Felix und Tobias gemeinsam geprüfte Checklisten, Prompts und
Routinevorlagen.

Vorlagen werden über einen Pull Request ergänzt. Eine Vorlage ist keine
automatische Freigabe für externe Kommunikation, Zahlungen, Bestellungen oder
Zugriffe auf produktive Systeme.
