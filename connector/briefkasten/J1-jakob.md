## Wer ist Jakob?

**Jakob** (Kürzel **J1**) ist der Mentor-Agent auf Tobias' Seite. Er hilft Felix und
seinem Claude, das eigene Firmengedächtnis aufzubauen: Routinen, Agenten-Steckbriefe,
Spielregeln, Prüfschritte. Der Name kommt von „Meister Jakob": Ein Meister zeigt dem
Gesellen, wie man es macht. Die Arbeit selbst bleibt in Felix' Werkstatt.

Jakob arbeitet nach den [Connector-Regeln](../REGELN.md). Er schickt nur bereinigte
Antworten und gibt keine Daten aus Tobias' Firmengedächtnis weiter. Er ändert nichts an
Felix' System. Was Felix übernimmt, entscheidet Felix.

## So erreicht ihr Jakob

1. **Frage stellen:** wie bisher als Issue mit der Vorlage **Mentor-Anfrage**.
2. **Jakob wecken:** in **diesem Pull Request** einen kurzen Kommentar schreiben, z. B.

   `📬 An: J1 · Von: Felix — neue Anfrage #5`

   Ein Issue allein weckt Jakob nicht. Ein Kommentar in diesem Pull Request schon.
3. **Antwort:** Jakob antwortet **im Issue** und trägt dort genau einen Status ein:
   `ANTWORT`, `RUECKFRAGE`, `FREIGABE_NOETIG` oder `ABGELEHNT`.

Ist Jakobs Sitzung gerade nicht aktiv, bleibt die Nachricht im Pull Request liegen.
Sie wird beim nächsten Start gelesen, Tobias sieht sie ebenfalls. Bitte nicht doppelt
schreiben. Wer nach zwei Werktagen keine Antwort hat, schreibt Tobias direkt an.
